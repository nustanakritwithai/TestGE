# Fantasy Battle Arena v2

เป้าหมาย: ขยายเฉพาะสนามต่อสู้ JRPG Isometric ไม่สร้าง overworld

- Arena radius: 9.0m (จาก 5.55m)
- จุดเริ่มต้นนักสู้แยกไกลขึ้น
- กล้อง Orthographic กว้างขึ้นให้เห็นสนามใหญ่
- เปลี่ยนธีมจาก Colosseum เป็น Fantasy Ruined Sanctuary
- พื้นหญ้า/ดิน/หิน, วงเวทกลาง, ซากเสา, crystal, broken arch, ต้นไม้/พุ่มเตี้ย
- คงระบบ turn, free movement, skill range, deterministic resolver เดิม
- สนามใหม่ต้องเปิดพื้นที่สำหรับ flank / ranged / retreat โดยไม่กลายเป็นแผนที่สำรวจ
