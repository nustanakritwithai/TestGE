P15 Definition

Client Prediction ใน TWA ไม่มีสิทธิ์แก้ World Truth ฝั่ง Server. Local client สามารถคาดการณ์เพื่อให้ input ตอบสนองทันที แต่ทุกครั้งที่ authoritative delta มาถึง client จะยึด state ของ server เป็นฐาน แล้ว replay เฉพาะ input ที่ server ยังไม่ acknowledge.
