ข้อจำกัด

โมเดลใน E13 เป็น neural models ขนาดเล็กที่ฝึกจริงใน browser เพื่อปิดช่องว่าง “untrained prototype kernel” แต่ยังไม่ใช่ PyTorch production GNN. จุดประสงค์รอบนี้คือพิสูจน์ pipeline Dataset → Train → Validation → Test → Checkpoint → Benchmark แบบไม่รั่วข้อมูลก่อนย้ายไปโมเดลจริงที่ใหญ่ขึ้น
