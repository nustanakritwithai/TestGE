3) Pareto: คุณภาพ vs ต้นทุนรวม

4) Net Adaptive Gain

Net Adaptive Gain = Benefit from better skill selection − Context extraction cost − Routing / Capability cost − Verification cost − Fallback cost Baseline = Expert Fixed Hybrid Adaptive candidates = Heuristic / Capability / Validity+Verification / Fallback / Event-driven
